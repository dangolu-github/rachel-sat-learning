# Rachel SAT Learning

Learner-facing Class 00 handout and ten-question practice. Private answers, teacher notes, source maps and learner records are excluded.

Homework uses a separate server-side submission service. Corrections appear only after an accepted attempt.

Learning navigation: Class Logbook, Question-Type Practice (`practice/`), Vocabulary Lab (`vocabulary/`), and Mistake Logbook (`mistakes/`). Practice currently links to existing Class 00 homework; remaining categories and vocabulary themes are future routes, not extra assignments. The Mistake Logbook redirects to the private service and shows only the current browser’s accepted wrong/blank answers. No Teacher entry is shown on learner pages.
