# Rachel SAT Learning

Learner-facing Class 00 handout, ten-question homework, and independent Question-Type Practice. Private answers, teacher notes, source maps and learner records are excluded.

Homework uses a separate server-side submission service. Corrections appear only after an accepted attempt.

Learning navigation: Class Logbook, Question-Type Practice (`practice/`), Vocabulary Lab (`vocabulary/`), and Mistake Logbook (`mistakes/`). Question-Type Practice has 30 independently submitted optional sets across ten skills (634 questions). These are separate from Class 00 Homework 1. Vocabulary themes remain a roadmap. The Mistake Logbook redirects to the private service and shows only the current browser’s accepted wrong/blank homework and practice answers. No Teacher entry is shown on learner pages.


Mock Tests (`mock-tests/`): five official fixed-route Reading and Writing forms, each with 27 Module 1 questions plus a selected lower/higher 27-question Module 2. Public pages contain navigation only. Questions, keys, source maps, drafts and results stay in the private service; mock tests open without an access code and retain the current browser’s saved-work session. Submission returns correct counts only after persisted readback and makes the result available in the owner-only Teacher dashboard.
